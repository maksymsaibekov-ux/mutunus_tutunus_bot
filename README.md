# mutunus_tutunus_bot
Telegram ШІ-бот на Python (Gemini 2.0 Flash)
Мутун Тутун — це Telegram-бот із ШІ, який відповідає українською, пам'ятає розмову й користувача та вміє відповідати за змістом завантажених документів.

Що вміє

Спілкування. Відповідає на питання через велику мовну модель gpt-oss-120b (Groq API). Характер і стиль задає системний промпт.
Пам'ять діалогу. Пам'ятає останні 10 повідомлень, а пам'ять зберігається в базі, тож не зникає, коли сервер засинає.
Довготривала пам'ять. Сам помічає факти про користувача (ім'я, місто, хобі) і додає їх у наступні відповіді. Керування: /remember, /memory, /forget.
Робота з документами (RAG). Приймає PDF, DOCX і TXT, ділить на шматки, зберігає у векторній базі й відповідає за змістом файлу. Керування: /docs, /cleardocs.
Захист. Перевірка секретного заголовка вебхука, білий список Telegram ID, ключі лише в змінних середовища, помилки приховані від користувачів.
